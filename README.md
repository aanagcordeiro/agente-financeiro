# 💰 Agente Financeiro Inteligente

## 1. Documentação do Agente
Este projeto consiste em um agente financeiro que auxilia usuários com dúvidas sobre finanças pessoais.

- Caso de uso: ajudar pessoas a economizar, investir e controlar dívidas  
- Persona: pessoas iniciando sua organização financeira  
- Arquitetura: sistema simples baseado em perguntas e respostas  
- Segurança: não utiliza dados reais, apenas simulação  

## 2. Base de Conhecimento
O agente utiliza informações básicas sobre:
- economia  
- investimentos  
- dívidas  

## 3. Prompts
Exemplos de perguntas:
- Como economizar dinheiro?
- Como investir?
- Como sair das dívidas?

## 4. Aplicação
Aplicação em Python que responde perguntas do usuário.

## 5. Avaliação
- Clareza das respostas  
- Utilidade das respostas  

## 6. Pitch

Este projeto apresenta um agente financeiro simples que auxilia usuários com dúvidas sobre finanças pessoais.

A solução permite interação por meio de perguntas e respostas, ajudando na tomada de decisões básicas como economia, investimentos e controle de dívidas.

O objetivo é demonstrar de forma prática o conceito de um agente inteligente aplicado ao contexto financeiro.
